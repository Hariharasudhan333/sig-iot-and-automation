# Day-5-
Day 5: WiFi Connection with ESP32
In this project, we will connect the ESP32 to Wokwi’s virtual WiFi network and display the IP address assigned to the board in the Serial Monitor.

Hardware Required
ESP32 DevKit v1
No additional components are required.

WiFi Configuration
Network: Wokwi-GUEST
Password: Leave blank

Wokwi Simulation
Start the Wokwi simulation.
Open the Serial Monitor.
Wait for the ESP32 to establish a WiFi connection.
Once connected, check the Serial Monitor.
The assigned IP address will be displayed.
## Wokwi simulation[https://wokwi.com/projects/476560837443143681]
